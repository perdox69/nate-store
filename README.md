# nate.store12 E-commerce Demo

เว็บร้าน nate.store12 แบบ responsive สำหรับเดโมลูกค้า เน้นสินค้า Ari, accessories, set จับคู่, สั่งผ่าน LINE, ตะกร้า checkout และ dashboard หลังบ้าน

## ใช้งาน

```bash
npm install
npm run dev
```

## ทดสอบ

```bash
npm test
npm run build
```

## ฟีเจอร์ที่มี

- Responsive ใช้งานได้ทั้งมือถือและคอม
- ระบบสมาชิกแบบ demo เก็บใน localStorage
- จัดการสินค้า ราคา หมวดหมู่ แบรนด์ และสต๊อกใน dashboard
- หมวดสินค้าแบบร้านจริง: สินค้าขายดี, สินค้าใหม่, Set จับคู่, Set ตามงบ, ถุงเท้า Ari, เชือกรองเท้า, กระเป๋า, เสื้อ Ari
- Filter หมวด แบรนด์ ราคา และ popular search
- หน้า product detail รองรับสี ไซซ์ โปรรวมส่ง/สกรีนฟรี/ถุงฟรี และปุ่มสั่งผ่าน LINE
- ตะกร้าสินค้า เพิ่ม ลด และคำนวณยอดรวม
- ระบบสั่งซื้อพร้อมที่อยู่จัดส่ง
- วิธีชำระเงินแบบ demo: QR พร้อมเพย์, โอนผ่านธนาคาร, เก็บเงินปลายทาง
- สต๊อกลดอัตโนมัติหลังสร้างออเดอร์
- จัดการสถานะออเดอร์ในหลังบ้าน

## ข้อจำกัดของเวอร์ชันนี้

ยังไม่มี backend, database, upload รูป, auth จริง, และ payment gateway จริง เหมาะสำหรับส่งเดโม flow ให้ลูกค้าดูและต่อยอดเป็น production ต่อไป
